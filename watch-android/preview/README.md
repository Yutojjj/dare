# パソコンで実機の画面を確認する

`実機プレビュー.cmd` をダブルクリックすると、パソコン内のプレビューを起動して `http://127.0.0.1:8766/` を開きます。ADBで接続された時計が1台必要です。

時計の画面を約1秒おきにそのまま表示します。画面内クリックはタップ、ドラッグはスワイプとして時計に送られます。「画面を点灯」「アプリを開く」「戻る」も使えます。これらは実機操作なので、卓移動や実績保存を押すと共有データにも反映されます。

管理アプリ右上のウォッチデバッグからも「実機」タブで同じ表示を開きます。「HTML版」は従来のブラウザ画面なので、Wear OS専用画面とは別です。

接続が切れた場合は、時計の「ワイヤレスデバッグ」に表示された現在のIPと接続用ポートを使って `adb connect` し直してください。ペア設定用ポートとは異なります。

プレビューはパソコン自身（127.0.0.1）だけで待ち受けます。画面はこのパソコン内で取得し、外部サーバーへ送信しません。使わないときはブラウザを閉じるか「表示を一時停止」を押すと画面取得が止まります。

Pythonを直接使う場合：`python preview/server.py --adb "ADBのパス"`。
