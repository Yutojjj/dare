# 付け回しウォッチ APK

このAndroidプロジェクトは、Wear OSのWebViewで `https://dare-alpha-ten.vercel.app/watch/` を開きます。通常のキャスト・顧客管理画面は開きません。ウォッチ画面のHTML・CSS・JavaScriptをVercelへ公開すると、次回の読み込み時に画面が更新されます。APK内のJavaコードや権限を変更した場合は、APKの再配布が必要です。

試験用APKは `DareWatch-debug.apk` です。Galaxy Watch 4での実機確認はまだ行っていません。

## ビルド

Android Studioでこの `watch-android` フォルダーを開き、Android SDK 36とJDK 17を用意して `app` のDebug APKをビルドします。出力先は `app/build/outputs/apk/debug/app-debug.apk` です。Galaxy Watch 4へのインストールには、ウォッチの開発者向けオプションとワイヤレスデバッグを使います。

このAPKは開発用署名です。後でウォッチ上のAPK自体を更新する場合、同じ署名鍵を使う必要があります。Vercel上のウォッチ画面だけを更新する場合、APKの更新は不要です。

## 運用

- バージョン1.3は終了前のお知らせを複数選択できます。例：1分前と30秒前。それぞれ独立した通知予約として保存し、設定解除・一時停止・時間変更時にも更新します。以前の単一設定は引き継ぎます。

- バージョン1.2は設定画面の「通知・振動」タブに対応しています。終了前のお知らせ（なし・10秒・20秒・30秒・1分・2分・3分）、終了時のお知らせ、振動を端末ごとに保存します。画面変更は `watch/` をVercelへ公開してください。事前通知には1.2のAPKが必要です。

- バージョン1.1からAndroid側のタイマー通知と振動に対応しています。初回起動時に通知と「アラームとリマインダー」の許可を求めます。
- 公開済みのウォッチ画面の保存処理をAPK側で連携するため、この対応のためのVercel更新は不要です。開始・一時停止・延長・削除を通知予約に反映します。
- 通知をタップするとウォッチ画面を開きます。時計の再起動後も未通知の予約を復元します。
- 通知・振動は時計の通知設定やおやすみモード、省電力制御の影響を受けます。アラーム許可がない場合は時刻が遅れる可能性があります。強制停止中は通知できません。実機での確認は別途必要です。
- 今後のHTMLからは `DareWatchNative.vibrate(300)` で短い振動を呼び出せます。ブラウザ版ではこの機能の有無を確認してから呼び出してください。

- ウォッチがインターネットへ接続されている必要があります。
- アプリを開き直すと公開URLを再読み込みします。
- WebViewのローカル保存はウォッチ内に保存されます。PCブラウザのローカル保存とは自動同期しません。
- 画面の公開先を変更するときは `MainActivity.java` の `WATCH_URL` と `WATCH_HOST` を更新してAPKを再ビルドします。通常のHTML更新では再ビルドは不要です。
